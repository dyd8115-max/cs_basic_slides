# 개발자의 AI 활용법

컴퓨터 공학개론 과제 — AI 활용을 주제로 제작한 발표용 웹 프레젠테이션입니다.

Gemini 2.0 Flash(Google)를 실생활 문제에 직접 적용해 세 가지 AI 서비스를 구현하고, 개발 과정에서 경험한 AI의 가능성과 한계를 함께 발표합니다.

---

## 서비스 소개

### AI 건강 증상 분석기

기침·발열·두통 등 16가지 증상을 선택하거나 직접 입력하면 AI가 가능성 높은 질병 3가지와 치료법, 병원 방문 기준을 안내합니다.

### AI 생활비 분석기

카테고리별 월별 지출 데이터를 차트로 시각화하고, "32만원으로 감량해줘"처럼 자연어로 목표를 입력하면 AI가 절약 계획을 즉석에서 생성합니다.

### AI 스마트 네비게이션

출발지·도착지를 입력하면 실제 지도에서 경로와 소요시간을 계산하고, 날씨나 층수 조건을 채팅으로 알려주면 AI가 추가 소요시간을 반영합니다.
